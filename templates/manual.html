🧠 ¿Qué es NEXUS?

NEXUS v3 es tu orquestador inteligente de negocios. Coordina múltiples motores especializados y proveedores de IA para que tú solo veas el resultado. Soluciones simples a procesos complejos.

Principio: NEXUS dirige, nunca hace el trabajo sucio. Tú hablas, NEXUS actúa.

🚀 Arrancar NEXUS v3

Servidor principal

Motores individuales (puertos propios)

python motors/motor_atf.py # puerto 8004 python motors/motor_auth.py # puerto 8006 python motors/motor_teens.py # puerto 8005 python motors/motor_pagos.py # puerto 8007 python motors/motor_reportes.py # puerto 8008
