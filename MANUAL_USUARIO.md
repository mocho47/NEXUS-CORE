# MANUAL DE USUARIO - NEXUS V5.0 (OPTIMIZED)

## 🧬 CAMBIOS DE ADN (OPTIMIZACIÓN)
Hemos operado a Nexus para que sea más ligero y seguro para tu PC de 8GB RAM.

### 🛡️ MÓDULO DE AUTOPRESERVACIÓN (NUEVO)
*   **Monitor de Signos Vitales:** Antes de abrir un programa pesado (como Corel o Aspire), Nexus checa tu RAM.
*   **Si la RAM > 85%:** Se negará a abrirlo y te dirá: *"Jefe, estoy ahogado. Cierra algo primero."*
*   **Por qué:** Para evitar que tu PC se congele totalmente. Nexus te protege de ti mismo.

### 🚨 BOTÓN DE PÁNICO (KILL SWITCH)
*   Si Nexus se traba, se queda hablando solo o entra en bucle:
*   **Presiona:** `Ctrl + Alt + Q`
*   Esto mata el proceso inmediatamente. Sin preguntas.

### 🧹 LIMPIEZA
*   Eliminado `pywhatkit` (muy pesado). Ahora usamos `AppOpener` para todo, que es nativo y ligero.
*   Voz híbrida optimizada para no gastar recursos si la memoria está llena.
