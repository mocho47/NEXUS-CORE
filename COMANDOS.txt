COMANDOS DE VOZ NUEVOS:
-----------------------
1. "NEXUS" -> Activa el sistema (Responde "Mande").
2. "ESTATUS" o "SISTEMA" -> Reporta uso de RAM y CPU.
   - Ejemplo: "Sistemas estables. RAM al 45%."
3. "SE TRABA" / "ESTÁ LENTO" / "SE CONGELA" -> Toma diagnóstico rápido y lo guarda en `C:\NEXUS\logs`.
   - Tip: también puedes decir "reporte rendimiento".
4. "DIAGNOSTICO" -> chequeo completo (dependencias/recursos + Supabase URL/DNS/TCP/keepalive si aplica).
5. "AYUDA" o "COMANDOS" -> imprime la lista actual (NEXUS_COMMANDS.md).
4. "DETECTA ACTIVIDAD PARANORMAL" -> Módulo de escáner con sonido.
   - (Emite beeps de radar y da un reporte aleatorio).
5. "CUÉNTAME UN CHISTE" -> Cuenta chistes variados.
6. "BUSCA [TEMA]" -> Busca en Wikipedia/Web.
   - Ejemplo: "Busca quién fue Nikola Tesla".
7. "CÁLLATE" / "SILENCIO" -> Detiene a Nexus mientras habla.
